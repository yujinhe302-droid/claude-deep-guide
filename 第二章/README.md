# 第二章：桌面端——下载安装与三界面使用详解

> 本章适合人群：想要最快上手 Claude、日常对话 + 轻量项目协作都需要覆盖的用户。桌面端是三种使用方式中**门槛最低、体验最完整**的一种，强烈推荐作为入门首选。

---

## 2.1 下载与安装

### 支持平台

| 平台 | 支持情况 |
|------|----------|
| macOS | ✅ 支持（Apple Silicon & Intel） |
| Windows | ✅ 支持（Windows 10/11） |
| Linux | ❌ 暂不支持桌面端，请使用 CLI |

### 下载步骤

1. 打开官网：[https://claude.ai/download](https://claude.ai/download)
2. 根据你的系统选择对应版本下载
3. macOS 用户：将 `.dmg` 文件拖入 Applications 文件夹
4. Windows 用户：运行 `.exe` 安装包，按提示完成安装
5. 安装完成后打开 App，使用你的 Claude 账号登录

> ⚠️ **注意**：需要提前注册好 Claude 账号，并确保网络环境可以正常访问 Anthropic 服务（国内用户请确保科学上网工具已开启）。

### 登录方式

- **使用会员账号登录**：直接用邮箱 + 密码登录，会员套餐内的额度自动生效
- **使用 API Key 登录**：在设置中填入你的 Anthropic API Key，按 Token 用量计费

## 2.2 桌面端三大界面总览

Claude 桌面端 APP 包含三个核心界面，每个界面的定位和使用场景各不相同：

| 界面 | 名称 | 核心定位 |
|------|------|----------|
| 界面一 | **Chat（聊天）** | 日常对话、问答、写作、论文等通用任务 |
| 界面二 | **Cowork** | 多步骤协作任务，适合有结构的工作流 |
| 界面三 | **Claude Code** | 代码生成与调试，直接操控终端执行命令 |

下面逐一详细介绍。

---

## 2.3 界面一：Chat 聊天界面

### 功能定位

Chat 界面是使用频率最高的界面，和你平时在网页版 claude.ai 上的体验基本一致。适用于：

- 日常问答与信息查询
- 文章撰写、改写、润色
- **学术论文写作**（逐段讨论、逐节修改）
- 翻译、总结、数据分析
- 头脑风暴与方案制定

### 主要功能

#### 新建对话
点击左侧边栏的 **「+ New Chat」** 按钮，即可开启新的对话。每个对话是独立的上下文，互不干扰。

#### 上传文件与图片
支持直接拖拽或点击上传：
- 文档：PDF、Word、TXT、Markdown 等
- 图片：PNG、JPG、WEBP 等
- 代码文件：直接粘贴或上传 `.py` `.js` 等文件

#### 选择模型
在对话框上方可以切换使用的模型（如 Claude Sonnet、Claude Opus 等），不同模型在速度和能力上有差异：

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| Claude Haiku | 最快、最省额度 | 简单问答、快速摘要 |
| Claude Sonnet | 速度与能力均衡 | 日常主力使用 |
| Claude Opus | 能力最强、消耗最大 | 复杂推理、论文深度写作 |

#### Projects（项目）
Chat 界面支持创建 **Project**，可以：
- 将相关对话归档到同一个项目中
- 为项目设置**系统提示词（System Prompt）**，让 Claude 记住你的固定背景信息
- 在项目内上传参考文档，作为 Claude 的长期知识库

> 💡 **推荐做法**：如果你在写学术论文，可以为每篇论文创建一个 Project，把文献资料、写作风格要求、论文框架都放进去，后续对话 Claude 会始终记住这些背景。

## 2.4 界面二：Cowork 界面

### 功能定位

Cowork 界面更像一个**结构化的协作空间**，适合需要分步骤、多轮迭代完成的任务。与 Chat 的自由对话不同，Cowork 更侧重任务管理和流程追踪。

适用于：
- 有明确目标的多步骤任务（如：「帮我整理这份报告，分三步完成」）
- 需要对输出结果进行版本管理和对比的场景
- 团队协作内容整理（个人使用时也可用于自我工作流组织）

### 主要功能

- **任务拆解**：可以将一个大任务拆成多个子任务，分步执行
- **内容区块管理**：每一步的输出都以独立区块呈现，便于回溯和修改
- **与 Chat 互补**：Chat 适合探索性对话，Cowork 适合执行性任务

> 💡 **使用建议**：当你有一个明确的交付目标（比如写一份完整的研究报告、整理一套教学大纲），用 Cowork 界面会比 Chat 更有条理。

---

## 2.5 界面三：Claude Code 界面

### 功能定位

Claude Code 界面是桌面端最强大的界面，它赋予 Claude **直接操控你本地终端的能力**。Claude 可以：

- 读写本地文件
- 执行终端命令
- 创建和管理项目目录
- 安装依赖、运行脚本
- 直接帮你部署项目到 GitHub

这意味着你不再只是和 Claude 聊代码，而是让 Claude **真正动手帮你写代码、跑代码、解决报错**。

### 主要功能

#### 连接本地环境
首次使用时，需要授权 Claude Code 访问你的本地终端。授权后，Claude 可以在你指定的目录范围内进行文件操作。

#### 执行任务的典型流程

```
你：帮我创建一个 Python 爬虫项目，抓取XX网站的数据，保存为 CSV
Claude Code：
  ① 创建项目目录结构
  ② 编写爬虫代码
  ③ 安装所需依赖（pip install ...）
  ④ 运行脚本测试
  ⑤ 反馈结果，遇到报错自动修复
```

#### 权限管理
Claude Code 在执行每个敏感操作（如删除文件、运行命令）之前，会**弹出确认提示**，你可以选择：
- **Allow Once**：仅允许本次操作
- **Allow Always**：本次会话内始终允许
- **Deny**：拒绝执行

> ⚠️ **安全提示**：不建议无限制地选择「Allow Always」，对于文件删除、网络请求等操作，建议逐次确认，避免误操作。

#### 配合 MCP 扩展能力
Claude Code 界面支持加载 **MCP（Model Context Protocol）** 插件，可以让 Claude 连接更多外部工具，例如：
- 读取 Notion / 飞书文档
- 操作数据库
- 调用第三方 API

（MCP 的详细使用方法将在**第七章**专门介绍）

## 2.6 三界面对比总结

| 对比维度 | Chat | Cowork | Claude Code |
|----------|------|--------|-------------|
| 主要用途 | 通用对话与写作 | 结构化协作任务 | 代码执行与项目开发 |
| 学习门槛 | ⭐ 极低 | ⭐⭐ 较低 | ⭐⭐⭐ 中等 |
| 是否操控本地文件 | ❌ | ❌ | ✅ |
| 适合场景 | 论文、写作、问答 | 报告整理、任务拆解 | 编程、部署、自动化 |
| 推荐人群 | 所有用户 | 有工作流需求的用户 | 有编程需求的用户 |

## 2.7 使用额度与限制说明

无论使用哪个界面，桌面端的使用额度统一受账号套餐限制：

- **Free 用户**：每天有基础免费额度，超出后需等待重置或升级
- **Pro 用户（$20/月）**：每5小时有使用量上限，达到上限后会临时限速，不会完全断用
- **Max 用户（$100/$200/月）**：更高的使用量上限，适合重度用户

> 💡 **小技巧**：如果你在用 Claude Code 执行大型任务时遇到额度限制，可以暂时切换到 Chat 界面继续轻量工作，等待额度恢复。
