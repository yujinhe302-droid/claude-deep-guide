# 第五章：用 Claude 进行数据分析——不懂代码也能跑出论文结果

> 本章面向零代码基础的同学。你不需要会 Python，不需要懂统计语法，只需要有数据、有问题，剩下的交给 Claude。

---

## 5.1 为什么用 Claude 做数据分析？

传统做数据分析的方式对新手非常不友好：

| 工具 | 门槛 | 痛点 |
|------|------|------|
| SPSS | 中等 | 操作繁琐，输出格式死板，高级分析（SEM、中介调节）需要额外插件 |
| Stata | 较高 | 必须学命令语法，报错看不懂 |
| R | 很高 | 配环境就能劝退一半人 |
| Python | 很高 | 同上，还要自己选库 |

**用 Claude 的方式：**

> 你只需要把数据扔给它，用中文告诉它你想做什么分析，它帮你写代码、运行、出图、解释结果，甚至帮你把结果写成论文里的那段话。

这对文科生、管理学、教育学、社会学方向的同学来说，是真正的降维打击。

## 5.2 桌面端 APP 三个窗口的分工

在开始之前，先理解 Claude 桌面端的三个窗口各自的职责：

```
┌─────────────────────────────────────────────────────┐
│                  Claude 桌面端 APP                    │
├───────────────┬────────────────┬────────────────────┤
│   Chat 窗口   │  Cowork 窗口   │  Claude Code 窗口  │
├───────────────┼────────────────┼────────────────────┤
│ 对话、提问    │ 协作处理文件   │ 执行代码、读写文件 │
│ 解释结果      │ 上传数据查看   │ 直接操作你电脑里   │
│ 写论文段落    │ 多轮协作修改   │ 的真实数据文件     │
│ 头脑风暴      │               │ 生成图表并保存     │
└───────────────┴────────────────┴────────────────────┘
```

**做数据分析时最常用的组合：**
- 用 **Chat** 描述需求、解读结果、撰写报告
- 用 **Claude Code** 直接让它读取你电脑里的数据文件、运行分析、输出图表

## 5.3 实战演示：从零开始用 Claude 跑一份完整分析

下面以一份**问卷调查数据**为例，完整演示从拿到数据到出结果的全流程。

### 第一步：准备好你的数据文件

将你的数据整理成 Excel（.xlsx）或 CSV 格式，放在一个你找得到的文件夹里。

**数据要求：**
- 第一行是变量名（表头）
- 每一行是一个样本
- 变量名最好是英文或拼音缩写（避免编码问题）

> 🖼️ 【截图】展示一份标准的问卷数据 Excel 截图，第一行为变量名，数据整齐排列

---

### 第二步：打开 Claude Code 窗口，告诉它你的数据在哪

在 Claude Code 窗口中，直接输入：

```
我有一份问卷数据，文件路径是：/Users/yourname/Desktop/survey_data.xlsx
请先读取这份数据，告诉我它有多少行、多少列、每个变量的基本情况。
```

> 🖼️ 【截图】Claude Code 窗口中输入路径指令后，Claude 返回数据基本信息的截图

Claude 会自动：
1. 读取你的文件
2. 返回样本量、变量数
3. 列出每个变量的类型、缺失值情况、基本统计量

---

### 第三步：描述性统计分析

让 Claude 生成一张标准的描述性统计表：

```
请对所有连续变量做描述性统计分析，
输出包含：样本量、均值、标准差、最小值、最大值、偏度、峰度，
结果保存为 Excel 文件，放在桌面。
```

> 🖼️ 【截图】输出的 Excel 描述性统计表截图

---

### 第四步：信效度检验（Cronbach's α + 因子分析）

这是问卷研究的必做环节，告诉 Claude：

```
这份问卷包含以下几个量表：
- 社交媒体使用量表：题目 SM1~SM5
- 社会比较量表：题目 SC1~SC4
- 自我效能量表：题目 SE1~SE5
- 心理健康量表：题目 MH1~MH6

请分别计算每个量表的 Cronbach's α 系数，
并对每个量表做验证性因子分析（CFA），
输出因子载荷、AVE、CR 值，以标准学术表格格式呈现。
```

> 🖼️ 【截图】Claude 输出的信效度检验结果表格截图

**Claude 返回的结果示例：**

| 量表 | 题项数 | Cronbach's α | AVE | CR |
|------|--------|-------------|-----|-----|
| 社交媒体使用 | 5 | 0.847 | 0.523 | 0.861 |
| 社会比较 | 4 | 0.812 | 0.501 | 0.833 |
| 自我效能 | 5 | 0.876 | 0.548 | 0.879 |
| 心理健康 | 6 | 0.891 | 0.562 | 0.903 |

> ✅ α > 0.7，AVE > 0.5，CR > 0.7，信效度良好，可以进入下一步分析。

---

### 第五步：相关分析

```
请做各潜变量之间的 Pearson 相关分析，
输出相关系数矩阵，矩阵对角线显示各变量的均值和标准差，
显著性用 * p<0.05，** p<0.01，*** p<0.001 标注。
```

> 🖼️ 【截图】相关系数矩阵表格截图

---

### 第六步：中介效应分析（以链式中介为例）

这是管理学、社会学、教育学论文里最常见的高级分析之一：

```
请做链式中介分析，模型结构如下：
- 自变量 X：社交媒体使用（SM_mean）
- 中介变量 M1：社会比较（SC_mean）
- 中介变量 M2：自我效能（SE_mean）
- 因变量 Y：心理健康（MH_mean）

请使用 Bootstrap 方法（重复抽样 5000 次），
输出直接效应、间接效应及 95% 置信区间，
按照学术论文标准格式整理结果表格。
```

> 🖼️ 【截图】Claude 运行 Bootstrap 中介分析的过程截图

**Claude 输出的中介效应结果示例：**

| 效应路径 | Effect | Boot SE | Boot LLCI | Boot ULCI |
|---------|--------|---------|-----------|-----------|
| 总效应 X→Y | -0.312 | 0.048 | -0.407 | -0.218 |
| 直接效应 X→Y | -0.124 | 0.051 | -0.224 | -0.024 |
| 间接效应1 X→M1→Y | -0.098 | 0.031 | -0.163 | -0.041 |
| 间接效应2 X→M2→Y | -0.053 | 0.022 | -0.101 | -0.014 |
| 链式中介 X→M1→M2→Y | -0.037 | 0.018 | -0.076 | -0.007 |

> ✅ 置信区间均不包含 0，中介效应显著成立。

```
3. 链式中介模型的路径图（显示路径系数和显著性标注）
4. 各组别心理健康得分的箱线图
```

## 5.4 进阶：让 Claude 做 Stata 计量分析

如果你的研究是计量经济学方向（面板数据、工具变量、DID 等），Claude 也可以帮你写 Stata 代码。

### 使用方式

在 Chat 窗口里描述需求，Claude 帮你生成 do 文件代码：

```
我有一份中国31个省份2010-2022年的面板数据，
变量包括：GDP对数值、数字经济发展指数、人力资本、
FDI、政府支出占比、城镇化率。

我想研究数字经济对经济增长的影响，
请帮我写 Stata 代码，依次做：
1. 描述性统计（tabstat）
2. 面板设定（xtset）
3. 混合OLS、固定效应、随机效应回归
4. Hausman 检验
5. 工具变量回归（2SLS）
6. 稳健性检验（替换变量、缩尾处理）
代码里加上详细注释，我是 Stata 新手。
```

> 🖼️ 【截图】Claude 生成的完整 Stata do 文件代码截图

Claude 生成代码后，你直接复制到 Stata 运行即可。遇到报错，把错误信息贴回来，Claude 帮你排查。

### 让 Claude 解读 Stata 输出结果

Stata 的回归输出对新手来说很难读懂，把输出结果截图或复制给 Claude：

```
这是我的固定效应回归结果，请帮我：
1. 解释每个系数的含义
2. 判断核心变量是否显著
3. 把这段结果写成论文里「实证结果分析」的段落
[粘贴 Stata 输出内容]
```

## 5.5 常见问题与技巧

### ❓ Claude 说找不到我的文件怎么办？

确认文件路径格式正确：
- **Mac**：`/Users/你的用户名/Desktop/data.xlsx`
- **Windows**：`C:/Users/你的用户名/Desktop/data.xlsx`

路径中不要有中文字符或空格，建议把文件放到桌面或一个简单路径的文件夹里。

---

### ❓ 代码运行报错怎么办？

把报错信息直接复制给 Claude：

```
运行你给我的代码时报错了，错误信息如下：
[粘贴报错内容]
请帮我修复。
```

Claude 会自动定位问题并给出修复后的代码。

---

### ❓ 如何保证分析结果是可重复的？

让 Claude 在代码开头加上随机种子：

```
请在代码开头加上 random_state=42，保证每次运行结果一致。
```

---

### ❓ Claude 能直接帮我写结果部分吗？

可以，而且写得相当规范。建议提示语里说清楚：
- 期刊/学位论文的引用格式（APA/MLA/国标）
- 字数要求
- 是否需要包含统计量（如 β=0.31, p<0.001）
