# 第一章：Claude 产品全貌与选择逻辑

> 本章目标：搞清楚 Claude 到底有哪些入口、怎么付费、用哪个版本最合适。  
> 适合人群：第一次接触 Claude，或者用了一段时间但还没搞清楚产品体系的用户。

---

## 1.1 Claude 是什么？

Claude 是由 Anthropic 公司开发的 AI 助手，和 ChatGPT、Gemini 同属大语言模型（LLM）产品。Claude 的核心优势在于：

- **长文本处理能力强**：支持超长上下文窗口，非常适合处理论文、报告、代码项目等长文档
- **指令遵循准确**：对复杂、多步骤任务的理解和执行比较稳定
- **代码能力突出**：在代码生成、调试、项目级编程上表现优秀
- **安全性设计**：Anthropic 在 AI 安全方向投入大量研究，输出内容相对克制

---

## 1.2 Claude 的三个使用入口

Claude 目前有三种主要的使用方式，面向不同的使用场景和用户群体：

| 入口 | 名称 | 适合人群 | 核心优势 |
|------|------|----------|----------|
| 🖥️ 桌面端 App | Claude Desktop | 普通用户、内容创作者、学术写作 | 开箱即用，界面友好，有独立的 Coworker 和 Claude Code 窗口 |
| 💻 VS Code 插件 | Claude Code Extension | 开发者、程序员、项目协作 | 与代码编辑器深度集成，可视化文件结构，适合完整项目开发 |
| ⌨️ 命令行 CLI | Claude Code CLI | 进阶用户、喜欢终端操作者 | 最灵活，可脚本化，稳定性高，无频繁压缩问题 |

> 💡 **重要说明**：这三个入口本质上都是访问同一个 Claude 模型，登录同一个账号后，会员额度是共享的，不需要分别购买。

---

## 1.3 两种付费方式

使用 Claude 有两种完全不同的付费逻辑，适合不同类型的用户：

### 方式一：订阅会员（推荐普通用户）

按月/年订阅，价格固定，适合日常高频使用。登录账号后，三个入口（桌面端、VS Code、CLI）均可使用，额度共享。

| 套餐 | 月付价格 | 年付价格 | 核心特权 | 适合场景 |
|------|----------|----------|----------|----------|
| **Free** | 免费 | 免费 | 有限次数使用 Sonnet 模型 | 轻度体验，了解 Claude 基础能力 |
| **Pro** | $20/月 | $17/月（年付 $200）| 5x 免费额度，支持 Sonnet 4.5，含 Research 功能、Google Workspace 集成、远程 MCP 连接 | 个人用户、学生、研究写作 |
| **Max $100** | $100/月 | — | Pro 的 5x 额度，含 Opus 4.5 访问权限，优先响应 | 专业内容创作者、需要长时间连续使用 |
| **Max $200** | $200/月 | — | Pro 的 20x 额度，全模型访问（含完整 Opus 4.5），优先响应，早期功能 | 重度用户、高强度开发、企业专业人员 |
| **Teams** | $25/人/月（年付）| — | 5人起，共享工作区，协作功能 | 团队协作、小型企业 |

> ⚠️ **关于使用限额**：订阅会员并非"无限使用"。每个套餐在一定时间窗口内有使用量上限，达到上限后会暂时限速或暂停，等待额度重置后恢复。使用越频繁、对话越长，消耗越快。Max 套餐的额度远高于 Pro，适合重度用户。

### 方式二：API 按量计费（推荐开发者）

通过 Anthropic API 接入，按实际消耗的 Token 数量付费，没有固定月费，用多少付多少。

| 模型 | 输入（每百万 Token）| 输出（每百万 Token）| 适用场景 |
|------|---------------------|---------------------|----------|
| Claude 4.5 Opus | $5.00 | $25.00 | 最强推理，复杂分析，Agent 任务 |
| Claude Sonnet 4.5 | $3.00 | $15.00 | 日常生产力，大文档处理 |
| Claude 4.5 Haiku | $1.00 | $5.00 | 快速任务，高并发，成本敏感场景 |

> 💡 **API 的核心优势**：可以集成到自己的应用、工作流或自动化脚本中；Claude Sonnet 4.5 通过 API 支持高达 **100 万 Token** 的超长上下文窗口（订阅版暂未开放此功能）；支持批量处理（Batch API），享受 50% 折扣。

> ⚠️ **API 的注意事项**：费用随使用量波动，需要在 Anthropic Console 监控用量，防止意外超支。不适合不懂技术的普通用户。

## 1.4 三个入口详细对比

### 桌面端 App（Claude Desktop）

**下载地址**：[claude.ai/download](https://claude.ai/download)，支持 macOS 和 Windows。

桌面端是最适合新手上手的入口，安装即用，无需配置。界面上有三个独立窗口区域：

| 窗口 | 功能 |
|------|------|
| 聊天窗口 | 日常对话、写作、分析、翻译等通用任务 |
| Coworker 窗口 | 可以让 Claude 作为"同事"协助完成更复杂的多步骤任务 |
| Claude Code 窗口 | 内嵌的代码辅助功能，可以直接在桌面端执行简单的编程任务 |

**适合做什么**：
- 论文写作与修改
- 长文档分析
- 日常问答与头脑风暴
- 内容创作（公众号、小红书文案等）

---

### VS Code 插件（Claude Code Extension）

**安装方式**：在 VS Code 扩展商店搜索 `Claude Code`，安装后登录账号即可使用。

VS Code 插件将 Claude 深度嵌入到代码编辑器中，最大优势是**可以直接看到 Claude 生成、修改的所有文件**，工作流完全可视化。

| 特性 | 说明 |
|------|------|
| 文件树可视化 | 实时查看 Claude 创建和修改的项目文件结构 |
| 代码内嵌辅助 | 在编辑器内直接查看代码建议和修改 |
| MCP 支持 | 可加载多个 MCP 服务器，实现多工具协同（数据库、浏览器、API 等）|
| 对话历史 | 保留完整的操作记录，便于回溯 |

**适合做什么**：
- 完整项目的代码生成与重构
- 需要清晰看到文件结构变化的开发任务
- 多工具协同的复杂自动化工作流
- 代码调试与优化

---

### 命令行 CLI（Claude Code CLI）

**安装方式**：需要先安装 Node.js，然后通过 npm 全局安装：

```bash
npm install -g @anthropic-ai/claude-code
```

安装完成后在终端输入 `claude` 即可启动。

CLI 是三种方式中**最灵活、最稳定**的，没有图形界面的限制，可以直接在终端操作系统文件、运行命令、执行脚本。

| 特性 | 说明 |
|------|------|
| 稳定性高 | 无 UI 渲染开销，对话压缩频率更低 |
| 脚本化 | 可以与 shell 脚本结合，实现全自动化流程 |
| 上下文控制 | 支持通过双击 ESC 回退到历史消息并重新编辑，同时回滚代码状态 |
| 轻量 | 资源占用少，适合在服务器或低配设备上运行 |

**适合做什么**：
- 熟悉终端操作的进阶用户
- 需要将 Claude 嵌入自动化脚本的场景
- 对稳定性和速度有较高要求的开发任务

## 1.5 怎么选择？一张图帮你决策

```
你是第一次用 Claude？
    ├── 是 → 下载桌面端 App，直接开始用
    └── 否 → 你主要用来做什么？
              ├── 写作/论文/日常问答 → 桌面端 App
              ├── 写代码/做项目 → VS Code 插件
              └── 熟悉终端/需要自动化 → CLI
```

| 你的需求 | 推荐入口 | 推荐套餐 |
|----------|----------|----------|
| 偶尔体验一下 | 桌面端 / 网页版 | Free |
| 学生写论文、日常创作 | 桌面端 | Pro ($20/月) |
| 职业内容创作者 | 桌面端 + VS Code | Max $100 ($100/月) |
| 重度开发者 / 每天大量使用 | VS Code + CLI | Max $200 ($200/月) |
| 构建自己的 AI 应用 | API | 按量付费 |

---

## 1.6 小结

- Claude 有三个使用入口：桌面端、VS Code 插件、CLI，三者共用同一个账号和额度
- 付费方式有两种：**订阅会员**（固定月费，适合个人用户）和 **API 按量计费**（适合开发者）
- 会员套餐从 Free → Pro → Max $100 → Max $200 逐级提升额度和模型权限
- 会员额度有上限，高频使用会触发限速，Max 套餐额度远高于 Pro
- 三个入口各有侧重：桌面端最易上手，VS Code 最适合项目开发，CLI 最灵活稳定
